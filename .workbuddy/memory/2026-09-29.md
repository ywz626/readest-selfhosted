- Android：`pnpm build-server-android`（aarch64）。
- **卡点与结论**：
  1. 首次构建 `next build` 停在 `✓ Running next.config.mjs` 之后完全卡死，
     CPU 几乎不涨。排查过：stdin、`.next` 缓存、沙箱（沙箱外同样卡死）都不是原因。
     真因是会话注入的 `NODE_OPTIONS=--require=.../node-language-shim.cjs`
     被构建 worker 继承。`unset NODE_OPTIONS` 后立刻推进到
     `Creating an optimized production build ...`。
  2. 随后报 `RangeError: Array buffer allocation failed`，再后来 tauri CLI 直接报
     `memory allocation of 302 bytes failed`。系统 24 GB 内存只剩约 2.9 GB 可用、
     可提交内存只剩约 234 MB（Memory Compression 已占 1.7 GB），属于机器整体内存耗尽，
     不是代码问题。需要用户先关掉占内存的程序再重新打包。
- 另发现：环境的 `rm` 被替换成坏的 `safe-bin/rm` shim（exit 127），必须用
  Python/PowerShell 删文件。
